# 蕫冬咚流体 IP：首版执行方案

- 状态：**首版已实现**，见文末「7. 首版实现结果」。本文件现兼作首版的任务说明与实现记录；[已确认的动画小样](./fluid-ip-demo.html) 是视觉基准，不是可直接上线的页面。
- 范围：继续使用 Hugo + 仓库内固定版本的 PaperMod，在**首页第一页的介绍区**加入形象。桌面端点击分离与回融；手机端只显示静态形象。**全站停用星野背景，但保留其源码文件。**
- 完成标准：站点中的形象、明暗配色和点击节奏接近小样，且文章阅读、首页原有文案与社交图标、键盘操作和构建均正常。交付可审查的本地改动与验证结果；不要推送或发布。

## 1. 已确认的视觉与行为

- 主体是首页昵称「蕫冬咚」的视觉化身，不另起名字，不做聊天或后端。保留小样中的一凹一突、不规则圆团、两只较大的圆眼；无猫耳、爪、胡须、尾巴。凹凸不需要附会额外故事。
- 同一轮廓有两套单色皮肤：亮色为墨黑身体、浅色眼睛；暗色为月白身体、深色眼睛。跟随站点现有 `html[data-theme]`，不新增主题按钮或饱和色。
- 点击时从主体边缘**长出**多个回声，缓慢拉开、短暂停留、再缓慢融合。回声是不规则、持续轻微拉伸和回弹的流体团，不是固定圆球；结束后不能在凹口漏出残影。小样目前显示 **3 团、全程约 4.5 秒**，这是首版视觉基准。回声数量由数据决定，代码不可假定永远只有 3 团。
- 回声未来可变成图标、文字等视觉形态，再回到主体。这是后续能力方向，**首版不实现具体变形目标，也不建设“任意元素变形引擎”**。
- 阅读优先：形象仅放首页介绍区，不延伸到文章正文、404、归档或全站固定层。桌面默认放介绍文字旁；窄屏可移到文案下方，但不能遮挡标题、正文、社交链接或下一篇文章卡片。

## 3. 运行细节

1. **静态优先**：Hugo 输出主体 SVG 与眼睛；JavaScript 失效时仍能看见形象。小样的主体路径、眼位、三团回声轨迹、果冻变形和约 4.5 秒节奏作为起点。小样的整页布局和“切换明暗”按钮不复制进博客。
2. **交互门控**：仅在首页介绍区确有形象、视口宽度至少 **900px**、`(hover: hover) and (pointer: fine)` 且未启用 `prefers-reduced-motion: reduce` 时启用点击。手机、粗指针、低于 900px 的窄屏与减少动态效果模式保留静态主体，不启动动画帧。CSS 与 JavaScript 使用同一门槛；无 JavaScript 时也只是静态形象。
3. **可访问性**：可交互时用真实按钮承载形象，提供能说明点击结果的中文名称、可见的 `:focus-visible`，支持 Enter/Space；静态状态不能留下一个点击后无反应的可聚焦按钮。SVG 内部装饰避免重复朗读。
4. **生命周期**：一次动画期间重复点击不叠加新循环。完成、页面隐藏或组件失效时都回到无残影的静止态；空闲时没有持续 rAF。切换明暗主题时直接由 CSS 变量同步主体、眼睛和回声，包括动画进行中。
5. **局部渲染**：首版使用小样已验证的局部 SVG 路径与 goo 滤镜。它只覆盖介绍区形象，不使用全屏 SVG 滤镜或全站 Canvas。主体与回声可用 PaperMod 的 `--primary`；眼睛应匹配首页背景（亮色的 `--code-bg`、暗色的 `--theme`），不能套用小样的固定底色。
6. **星野停用**：构建后的首页和文章页均不应再出现 `#starfield-canvas`，也不加载 `/js/starfield.js`。保留源码是为了将来可恢复，不等于继续运行；`starfield.css` 仍会被主题自动打包，需检查其现存层级规则没有干扰新布局。

### 7.2 与第 2 节任务说明的差异

1. **首页第二页仍会加载 `fluid-ip.js`**（该页无形象，脚本第一行即返回）。原因：`extend_footer.html` 由 `partialCached "footer.html" . .Layout .Kind ...` 渲染，首页各分页共用同一份缓存输出，任何按页码变化的条件（`eq .Paginator.PageNumber 1`）都会让第 1 页与第 2 页随机拿到对方的结果。因此条件只用 `.IsHome`，代价是分页页多一次约 1.1 KB（gzip）的无效请求；若要去掉，正确做法是把 `<script>` 放进只在第 1 页渲染的 `home_info.html`（未缓存），而不是在 `extend_footer.html` 里加页码判断。
2. **新增 `docs/design/fluid-ip-check.mjs`**：第 4 节要求的最小可运行检查需要一个可执行载体，按小样命名惯例放在设计记录旁。
3. **桌面不加负外边距**：小样 viewBox 左侧为空，视觉上就是与文案的间距；若用负 margin 收紧，按钮命中区会压到正文列最后约 16px，点行尾会误触发动画，因此保持为 0。
4. **静态态不切换 ARIA role**：按钮始终是 `<button>`，静态时 `disabled` 且无障碍名称改为描述形象的静态文案（`data-label-action` 保存可点击时的动作文案）。禁用按钮不可聚焦、不可点击，静态下不会留下“点了没反应”的控件。

## 8. 第二版：放大与变形试验

基于浏览器实看，首版主体实际可见宽度约为按钮宽度的一半，回声也被同一 `viewBox` 缩得很小。第二版将 SVG 画面范围从 `900×760` 收到 `800×720`，桌面按钮从 200px 放大到 300px；手机静态形象也相应放大。角色轮廓和约 4.5 秒的分离回融节奏保留。

每团回声仍先以不规则流体从主体边缘分离；到达远端后短暂转成一个 SVG 图案或文字，再恢复流体并回融。当前三种内容是星形、`文`、`</>`，只用于检验「图案与文字都能由回声承载」的视觉语言，不代表最终内容分类。变形内容与轨迹同在规格数组中，动画停止时同时清空流体路径与隐藏图案文字。

下一步先让人眼确认变形的尺寸、语义和节奏，再选**一个**真实导航场景做转场试验。转场应从被点击的回声出发，到目标页标题收束；普通链接必须保留，移动端与减少动态效果模式直接导航。不要在形象语言尚未确认时把过渡铺到全站。

## 9. 首页排版修正

第二版的双栏 Grid 让角色跨越标题和正文所在的行，导致左侧各行被撑开。现在恢复 PaperMod 的自然纵向排布，让标题、简介和社交图标回到紧凑的连续节奏。画面下沿收至 `800×680`。后续实看发现：角色 SVG 右侧预留了回声活动空间，若按整个 SVG 按钮对齐，静止时角色与文章卡片的中心线不一致；桌面端因此将按钮向右移约 88px，使**可见主体**的右沿对齐文章卡片右沿，左侧文案仍与卡片左沿对齐。简介宽 400px，可完整排成一行。移除悬停上浮和「点我」提示，静止时只呈现角色本身。浏览器分别检查 1280px、900px、390px 宽度与亮暗主题，确认无横向溢出；动画结束后回声与临时图案均被清空。

## 10. 入口层与吸附：代替文章点击前奏

文章链接的跳转时间太短，点击后先飞墨迹再跳页会迫使导航等待，实际观感不自然。此方案已撤下。当前保留 Hugo 的 `/` 文章列表与全部正常链接，在其上设置一个独立的入口状态：初访 `/` 时，页面只呈现放大的流体形象。点击或触摸形象后，它用约 1.4 秒移动并缩小到原有介绍区位置，文章列表显现。入口与列表共用同一个 SVG 元素，不复制角色；列表状态 URL 为 `/#articles`，浏览器返回可回到入口，直接打开该地址可跳过入口。无 JavaScript 时直接显示原列表，不出现空白入口。

进入后，文章卡片保持安静、立即导航。原先“回声游向卡片并变成标题首字”的试验被用户判定为乱蹦乱跳，已撤下。桌面精细指针移动时，两只眼睛只在主体内小幅跟随；手机和减少动态效果模式保持静态。入口的主体按可见轮廓而不是 SVG 画布居中。进入时仅让角色移动与缩小，背景逐渐变透明；角色本身保持不透明，并在同一帧落到介绍区，避免淡出后突然闪现。任意元素吸附仍是后续设计方向，本版不在文章卡片上试验。

实现位于 `layouts/partials/home_info.html`、`assets/css/extended/fluid-transition.css`、`assets/js/fluid-transition.js` 与 `assets/js/fluid-ip.js`。入口只影响首页第一页；文章页与其他列表页照常使用 PaperMod 页面。参考： [Hugo 模板类型](https://gohugo.io/templates/types/)、[PaperMod 项目覆盖方式](https://github.com/adityatelange/hugo-PaperMod/wiki/FAQs)。

## 11. 全站身份与阅读收尾

角色进入导航，成为全站可识别的首页标记；通过 PaperMod 原生 `params.label.iconSVG` 注入，不覆盖主题 header。文章末尾复用同一 SVG：它安静地趴在一小片墨迹上，配合「这一页，先读到这里。／再去翻翻」返回 `/#articles`，避免读完文章后被迫重播入口。正文、标签、前后篇导航维持原有顺序和宽度。

小形象在链接悬停或键盘聚焦时缓慢转动眼神，文末主体轻微舒展；不产生游走回声、不挪动文字、不延迟导航，不引入新的脚本或持续动画。手机和减少动态效果时保持静态。入口、首页大形象、全站小标记和文末角色沿用同一轮廓和主题双色。

## 12. 放出灵感，收回记忆

首页点击角色播放约 9.6 秒的有限动画。三团回声相隔 320ms 从主体分离：先保持柔软的不规则形态漂到预留空间，然后舒展、由模糊变清晰，形成文字或图案，停留后再软化并回融。每团的时间分配为分离 30%、塑形 15%、停留 21%、软化 14%、回融 20%。形态清晰期间位置固定，避免乱蹦的观感；文字软化完成后才开始回程。

三轮内容依次为「星形／文／代码」、「读／写／想」、「书／笔／月亮」，同一规格支持文字及 SVG 路径。全部展开后，再次点击主体可提前收回；略过的只有形态与位置都相同的停留时间，回融仍按原速度运行。分离与塑形期间的重复点击不并发、不重置。回到入口、隐藏页面或失去动画门槛均清空临时形态。

当前“软化”使用 SVG 模糊、缩放与墨团交叠实现，不是任意 DOM 的轮廓插值；文章正文和导航图标不会被移走。这一轮先建立可双向演出的形态语言，后续具体元素参与时复用同一节奏。

## 13. 页面由回声展开，也能被收回

第 12 节仍局限于角色旁的表演，未满足用户所指的「页面元素本身可以成为回声」。现在入口采用约 2.4 秒的页面编排：角色分出墨团，分别游向真实介绍标题、简介、三个社交链接及右下角的主题和返回顶部按钮。墨团舒展为墨迹，原位文字和图标从墨迹中展开；角色同时缩小落到介绍区，文章列表安静显现。

点击导航首页链接，会倒放同一条时间轴：这些真实元素收拢成墨团、回到角色，角色回到入口中央。DOM 元素及事件处理器保持原样，动画只暂时控制透明度、模糊和裁切；没有替换链接、克隆按钮或延迟文章导航。修饰键点击首页链接保持原生行为。手机与减少动态效果直接切换，页面隐藏、窗口调整、历史导航都结束并清理动画。滚动条保持占位，避免入口解锁时角色落点横向跳动。

这次参与的是首页介绍与功能入口；长篇正文不参与收拢。现有角色旁回声演出保留为点击彩蛋。变形为视觉连续的墨迹交接，尚不是对任意 DOM 像素进行流体模拟。
